Script: [`system_info.sh`](./system_info.sh)

## What the script does

| Requirement | How it is done |
|---|---|
| Prints current date | `CURRENT_DATE=$(date)` + `echo` |
| Prints hostname | `HOST_NAME=$(hostname)` |
| Prints username | `USER_NAME=$(whoami)` |
| Prints disk usage | `df -h` |
| Prints running processes | `ps aux` |
| Uses variables | `CURRENT_DATE`, `HOST_NAME`, `USER_NAME`, `DIR_NAME`, `FILE_NAME` |
| Takes user input | `read -p "Enter a directory name..." DIR_NAME` |
| Creates a directory | `mkdir -p "$DIR_NAME"` |
| Creates a file | `touch "$DIR_NAME/$FILE_NAME"` |
| Stores processes in the file | `ps aux > "$DIR_NAME/$FILE_NAME"` (output redirection) |

## How to run

```bash
chmod +x system_info.sh
./system_info.sh
```
